# Scouting Database (SQL Server)

This repository contains the SQL script **`SQL_Query_ScoutsDatabase.sql`**, which defines and/or queries a scouting database in **Microsoft SQL Server** format.

## File

- **SQL_Query_ScoutsDatabase.sql**  
  SQL script compatible with **SQL Server** (T-SQL).  
  You can open and run this file in tools such as:
  - SQL Server Management Studio (SSMS)
  - Azure Data Studio

## Usage

1. Open your SQL Server environment (e.g., SSMS).
2. Connect to your SQL Server instance.
3. Open `SQL_Query_ScoutsDatabase.sql`.
4. Execute the script to create or work with the scouting database, depending on what the script contains.
